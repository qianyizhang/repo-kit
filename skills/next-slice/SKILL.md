# Next slice

Choose the next useful action against the project's actual state.

- Follow local guidance to the relevant goals, implementation and verification.
  Use existing plans or work records; no particular tracker or document layout
  is required. Check previous decisions before reopening an idea.
- Compare serious candidates by value, readiness, dependencies and the smallest
  independent proof. Distinguish observed behavior from plans and unverified claims.
- Recommend one bounded outcome with its scope, evidence, and completion check.
  Briefly explain why it comes before the alternatives. Use a small comparison
  table only when it helps; name the prerequisite if nothing is ready.
- Investigate facts yourself. Use `grilling` only for material unresolved choices,
  preserving accepted decisions and existing authorization.

A recommendation does not grant write authority. Continue implementation when
already requested; otherwise finish with the recommended action.
