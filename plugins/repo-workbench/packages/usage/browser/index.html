Token accounting

Total = input + output. Cache read and cache write are included in input; reasoning is included in output. Reasoning share = summed reasoning ÷ summed output, not an average of percentages. Missing reasoning counters make the share a lower bound. Input cache share = cache read ÷ input. Response records take precedence over legacy snapshots in the same session.

Model pricing

Current Standard API rates apply to all history. . You can override rates in USD per million tokens. Estimates use uncached input, cache read, cache write and output separately. A blank model remains unpriced; unknown prices are never treated as free. These are API-equivalent estimates, not subscription charges or provider invoices. Prices stay in this browser and can be exported. Above 272K input tokens, eligible models use 2× input/cache rates and 1.5× output. Processing-tier and region premiums are not inferred. For older models with unpublished cache-write pricing, the displayed 0 only applies when no writes are recorded; records with writes stay unpriced. GPT-5.6 Sol uses the current promotional rate (available at least through November 21, 2026).

Sources and coverage

This report contains usage counters and source metadata only. It excludes prompts, message bodies, tool arguments, credentials and private reasoning. Refresh reads the configured roots; it never modifies the source logs. Generated HTML, JSON and CSV contain local paths and usage metadata.

Counter warnings mean the recorded input + output differs from total_tokens. They do not indicate failed requests. Only the inconsistent snapshot is excluded; valid records in the same session remain counted. Zero-component notices with a positive total are not assigned invented input/output. An absent metered record means no supported usage was found in that file.
