# MCP Apps in Repo Workbench

Shared principles and build sequence live in repo-kit's
`user/practices/mcp-apps.md`, installed as
`$CODEX_HOME/practices/mcp-apps.md`.

Repo Canvas uses `canvas_open` and `canvas_app`; its context owns the draft and
shared discussion. Apply updates the draft; Save writes the repository.
Session review and usage are read-only views over recorded local evidence.
Their standalone CLI/export paths and MCP views share renderers and readers.

See the [package README](../README.md) for entry points and verification, and
`docs/reviews/2026-10-22-mcp-apps.md` in repo-kit for provenance.
