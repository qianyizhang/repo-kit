# Example MCP App · early presentation trial

Superseded by the [whole-app anatomy round](../2026-10-22-whole-app-anatomy/README.md)
and the [implemented design](../../../../plugins/example-mcp-app/design.md).

The 22 October trial modeled Tools/Messages from source `041e0d3` using eight
broad regions. It improved a simulated flow but failed to map the whole actual
layout first. The user's correction established spatial decomposition before
journey analysis. That lesson is recorded in the
[skill review](../../../reviews/2026-10-22-ui-discussion.md).

The retired prototypes and their screenshots were removed after implementation.
They were simulations, not native-host acceptance evidence.
